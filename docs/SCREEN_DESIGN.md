## 画面遷移図

### 全体フロー

```mermaid
stateDiagram-v2
    [*] --> ホーム画面
    
    ホーム画面 --> ログイン画面: ログインが必要
    ホーム画面 --> 動画一覧画面: ログイン済み
    
    ログイン画面 --> ユーザー登録画面: 新規登録
    ログイン画面 --> 動画一覧画面: ログイン成功
    ユーザー登録画面 --> ログイン画面: 登録完了
    
    動画一覧画面 --> 動画詳細・再生画面: 動画選択
    動画一覧画面 --> キャプチャ一覧画面: キャプチャ表示
    動画一覧画面 --> 設定画面: 設定開く
    
    動画詳細・再生画面 --> 動画一覧画面: 戻る
    動画詳細・再生画面 --> キャプチャ一覧画面: キャプチャ表示
    
    キャプチャ一覧画面 --> 動画詳細・再生画面: 戻る
    キャプチャ一覧画面 --> 動画一覧画面: ホームに戻る
    
    設定画面 --> 動画一覧画面: 戻る
    設定画面 --> ログイン画面: ログアウト
```

### 詳細遷移図（シーケンス）

```mermaid
sequenceDiagram
    participant User
    participant Client
    participant Server
    
    User->>Client: アプリ起動
    Client->>Client: ホーム画面表示
    User->>Client: ログインボタン
    Client->>Client: ログイン画面表示
    User->>Client: 認証情報入力
    Client->>Server: POST /users/token
    Server-->>Client: access_token
    Client->>Client: トークン保存
    Client->>Server: GET /videos
    Server-->>Client: 動画一覧
    Client->>Client: 動画一覧画面表示
    User->>Client: 動画選択
    Client->>Server: GET /videos/{id}
    Server-->>Client: 動画詳細
    Client->>Client: 再生画面表示
    User->>Client: コメント表示指示
    Client->>Server: GET /jikkyo?...
    Server-->>Client: コメントデータ
    Client->>Client: コメント表示
```

## 画面詳細

### SCR001: ホーム画面

**説明**: アプリケーション起動時に表示される初期画面。ユーザーの認証状態を判定し、次の画面へ遷移。

**レイアウト:**
```
┌─────────────────────────────────────┐
│         CommentPlayer               │
│                                     │
│      ローカル動画視聴プレイヤー      │
│                                     │
│  ┌─────────────────────────────┐  │
│  │  ログイン       新規登録       │  │
│  │  [ボタン]      [ボタン]      │  │
│  └─────────────────────────────┘  │
│                                     │
│  ※ ログイン済みの場合は             │
│     自動的に動画一覧画面へ遷移      │
└─────────────────────────────────────┘
```

**主要要素:**
- CommentPlayerロゴ
- ログインボタン
- 新規登録ボタン

### SCR002: ログイン画面

**説明**: ユーザーがユーザー名とパスワードを入力してログインする画面。

**レイアウト:**
```
┌─────────────────────────────────────┐
│  CommentPlayer            ◀ 戻る    │
├─────────────────────────────────────┤
│                                     │
│         ログイン                    │
│                                     │
│  ユーザー名:                        │
│  [________________]                 │
│                                     │
│  パスワード:                        │
│  [________________]                 │
│                                     │
│  ┌─────────────────────────────┐  │
│  │  ログイン [ボタン]           │  │
│  └─────────────────────────────┘  │
│                                     │
│  新規登録は [こちら]                │
│                                     │
└─────────────────────────────────────┘
```

**入力フィールド:**
- ユーザー名（必須）
- パスワード（必須）

**レイアウト:**
```
┌──────────────────────────────────────────┐
│ ◀ 戻る                                    │
```

## 画面要素の詳細仕様

### 動画カード

```mermaid
graph TD
    A["動画カード"] --> B["サムネイル画像"]
    A --> C["動画情報"]
    C --> C1["タイトル"]
    C --> C2["解像度"]
    C --> C3["放送日"]
    C --> C4["コメント数"]
    A --> D["状態表示"]
    D --> D1["再生済みバッジ"]
    A --> E["アクション"]
    E --> E1["再生ボタン"]
    E --> E2["マイリストボタン"]
```

### コメント表示フォーマット

```
[時刻] | [ユーザー名] : [コメント内容]
例)
00:30 | user123: このシーンいいね！
```
